# RNA-seq Cloud Analysis Project 🚀

This project demonstrates how to build and deploy a cloud-based RNA-seq data analysis pipeline using open-source bioinformatics tools. It integrates steps from raw data processing to interactive visualization using Python, R, and cloud infrastructure. The end goal is to build a modular, reproducible, and containerized system that showcases real-world software engineering practices in bioinformatics.

## 🧪 Project Objectives

- Download and process RNA-seq FASTQ data
- Perform quality control (FastQC, MultiQC)
- Quantify gene expression (Salmon)
- Conduct differential expression analysis (R/DESeq2 or Python)
- Create an interactive API (FastAPI) to explore results
- Build a dashboard (Streamlit) for gene-level visualization
- Package the project using Docker for reproducibility
- Deploy everything on AWS EC2
